# Grilles SST Helper

Crée une application React standalone appelée "Grilles SST".

L'application est une seule page. Crée le fichier src/pages/Index.tsx avec exactement le code suivant, sans le modifier ni le réécrire

Stack : React + TypeScript + Tailwind. Lucide-react est la seule dépendance à ajouter si elle n'est pas déjà présente. Les données sont stockées en localStorage, aucune base de données n'est nécessaire.
